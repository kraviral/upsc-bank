# Framework Library

Thinking lenses for GS4 body sub-headings. Pick what fits the sub-heading; invent one if nothing here does. Never force-fit.

A good framework has three properties: it is exhaustive enough that the aspirant can generate points without recall, it is memorable under exam pressure, and its categories are visibly non-overlapping to the examiner.

## 1. Concept-specific frameworks

| Concept | Framework |
|---|---|
| Emotional intelligence | Goleman's **ARMES** — Awareness, Regulation, Motivation, Empathy, Social skills |
| Persuasion / communication | **Ethos, Pathos, Logos** (Aristotle) |
| Attitude | **ABC** — Affective, Behavioural, Cognitive |
| Attitude change | **Elaboration Likelihood** — central route (argument) vs peripheral route (cue) |
| Moral development | **Kohlberg** — pre-conventional → conventional → post-conventional |
| Values | Personal → Professional → Constitutional → Universal |
| Sources of ethics | Family, Peers, Religion, Education, Law, Media, Culture |
| Civil service aptitude | The syllabus list itself: integrity, impartiality, non-partisanship, objectivity, dedication to public service, empathy, tolerance, compassion |
| Conduct in public life | **Nolan's seven principles** — selflessness, integrity, objectivity, accountability, openness, honesty, leadership |
| Probity in governance | RTI · Citizen's Charter · Code of Ethics vs Code of Conduct · work culture · service delivery · utilisation of public funds · corruption |
| Corruption | Prevention → Detection → Punishment |
| Corporate governance | Shareholder vs stakeholder · CSR · whistleblower protection · triple bottom line |
| Environmental ethics | Anthropocentrism vs biocentrism vs ecocentrism · intergenerational equity · Gandhi's "enough for need, not greed" |
| International relations ethics | Realism vs idealism · sovereignty vs responsibility to protect · national interest vs global commons |
| Conscience | Inner voice · moral compass · Gandhi's inner voice at Bardoli · conflict with external authority |
| Accountability | Answerability → Enforceability → Responsiveness |
| Discretion | Rules ← → Discretion spectrum: rigidity vs arbitrariness, with reasoned decision-making as the balance |

## 2. General-purpose structural lenses

Use when the sub-heading is about causes, consequences, barriers or solutions.

| Purpose | Lens |
|---|---|
| Consequences and impact | Individual → Organisation → Society → Nation → Global |
| Barriers / causes | Individual → Institutional → Systemic → Societal |
| Solutions / way forward | Legal → Institutional → Behavioural → Technological |
| Any "how do I develop X" question | Head (knowledge) → Heart (attitude) → Hand (action) |
| Timeframe | Immediate → Short term → Long term |
| Governance actors | Political executive → Bureaucracy → Judiciary → Civil society → Citizen |
| Balanced evaluation | Merits → Limitations → Conditions under which it holds |
| Two-sided philosophical questions | Thesis → Antithesis → Synthesis |
| Ethics vs law | Legality → Morality → Practicality → Sustainability |
| Means and ends | Means-justified (Gandhi, Kant) ← → Ends-justified (Machiavelli, utilitarianism) |
| Public vs private morality | Private conscience → Professional duty → Constitutional obligation |

## 3. Case-study decision tests

Use these to justify the chosen course of action. Naming the test used is itself value addition.

- **Kidder's four dilemma paradigms** — truth vs loyalty · individual vs community · short term vs long term · justice vs mercy. Identify which paradigm the case belongs to; it names the dilemma precisely.
- **Kidder's three resolution principles** — ends-based (utilitarian), rule-based (Kantian), care-based (golden rule / ethics of care).
- **PLUS filter** — Policies, Legal, Universal, Self.
- **Blanchard–Peale test** — Is it legal? Is it balanced? How will it make me feel about myself?
- **Front-page test** — would this decision survive tomorrow's newspaper?
- **Rights–Justice–Utility triad** — whose rights, whose fairness, whose greatest good.
- **Stakeholder duty mapping** — for each stakeholder: their stake, the duty owed, the cost of ignoring them.

Sequencing tip for the chosen course of action: state the decision first, justify with one named principle, then split implementation into immediate / short-term / long-term. Examiners reward decisiveness; hedged answers that survey options without choosing lose marks.

## 4. Directive-word to framework mapping

| Directive | What it obliges | Natural structure |
|---|---|---|
| Discuss | Both sides, then a position | Thesis → Antithesis → Synthesis |
| Examine | Investigate components and validity | Dimension-wise breakdown |
| Critically examine / analyse | Examine, then judge with reasons | Dimensions → limitations → verdict |
| Elucidate / Explain | Clarify with illustration | Definition → dimensions → examples |
| Comment | Personal reasoned opinion, briefly justified | Position → 2–3 supports → nuance |
| Evaluate | Weigh worth against criteria | Criteria → performance → judgement |
| Substantiate | Support with evidence | Claim → evidence stack → reinforcement |
| Illustrate | Examples carry the answer | Concept → 3–4 diverse examples → inference |
| To what extent | Degree, not yes/no | Holds true when… → fails when… → net position |
